# Operator Checklist

## Before Hardware Testing

- [ ] Robot safety briefing completed.
- [ ] Emergency stop verified.
- [ ] Safety lead assigned.
- [ ] Test area cleared.
- [ ] Battery threshold satisfied.
- [ ] Network mode recorded.
- [ ] Firmware and SDK version recorded.
- [ ] Software version and Git commit recorded.
- [ ] Validation run created.
- [ ] Cameras or video references approved.

## During Hardware Testing

- [ ] Execute one case at a time.
- [ ] Record logs and timestamps.
- [ ] Record RobotState snapshots where applicable.
- [ ] Stop on unexpected motion or fault.
- [ ] Mark unsupported capability cases as `SKIPPED` with evidence.
- [ ] Mark ambiguous outcomes as `UNKNOWN`.

## After Hardware Testing

- [ ] Summarize HVP run.
- [ ] Complete daily log.
- [ ] File issue reports for failures.
- [ ] Attach evidence package.
- [ ] Complete acceptance or regression report.
- [ ] Obtain operator and safety sign-off.
